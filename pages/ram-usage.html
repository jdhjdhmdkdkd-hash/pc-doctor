How to Reduce RAM Usage on Windows

RAM, or Random Access Memory, is used by Windows and applications to temporarily store data that the computer needs while it is running. When available memory becomes limited, multitasking can become less responsive.

What Uses RAM?

Windows itself uses RAM, along with applications such as web browsers, games, video editors and other software. Browser tabs and extensions can also use a significant amount of memory.

1. Close Unused Applications

Close programs that you are no longer using. Keeping many applications open at the same time can increase memory usage.

2. Check Task Manager

Press Ctrl + Shift + Esc to open Task Manager. Then open the Processes tab and look at the Memory column.

This can help you identify applications that are currently using a large amount of RAM.

3. Manage Startup Apps

Some applications automatically start when Windows starts. Review your startup applications and disable programs that you do not need to launch automatically.

4. Reduce Browser Tabs

Having many browser tabs open can increase memory usage. Close tabs that you are finished with and remove browser extensions that you no longer need.

5. Restart Your PC

A restart closes running applications and clears temporary working memory. Restarting can sometimes help when memory usage has remained high for a long period.

6. Consider a RAM Upgrade

If your computer frequently runs out of available memory during your normal workload, installing additional compatible RAM may improve multitasking.
